# Learn Programming Books

A small collection of freely available programming books and open educational
resources for students.

This repository was made primarily to make good programming books easier to
find and share among students at school.

The collection currently covers:

- C
- C++
- JavaScript
- Python
- Rust

## Why?

There are many excellent programming books available freely on the internet,
but they are often scattered across different websites.

This repository collects a few of them in one place so that students can
easily discover and read them.

The books belong to their respective authors and copyright holders. This
repository does not claim ownership of any of the books.

## Attribution

A lot of work has gone into creating these books. Even when a work is freely
licensed, its authors deserve credit.

This repository therefore keeps attribution information for every included
work and links back to the original source whenever possible.

If you notice an incorrect attribution, missing license information, or a
problem with one of the files, please open an issue or submit a pull request.

## Contributing

If you would like to suggest another freely available programming book,
please make sure it is actually permitted to be redistributed before adding
it.

When adding a book, include:

- Title
- Author(s)
- Original source
- License
- Required attribution
- Original URL

Please preserve the original copyright and license notices.
